# Strikethrough – site bundle

A static site: `index.html` plus two data files. No build step, so any static host works.

```
index.html          the whole site (styles and script inline)
data/deals.json     checked deals (regenerated by build.py)
data/calendar.json  retailer sale dates
```

## Live address

https://strikethrough.com.au (hosted on Netlify)

## Go live today (about 15 minutes)

1. **Domain.** Check `strikethrough.com.au` (and `.com`) at any registrar, such as VentraIP, Crazy Domains or GoDaddy. A `.com.au` needs your ABN.
2. **Host.** Either:
   - **Fastest:** go to app.netlify.com/drop and drag this folder in. You get a live URL straight away.
   - **Best (auto-updating):** put this folder in a new GitHub repo, then import the repo in Vercel or Netlify. Every time the data files change in the repo, the site redeploys itself.
3. **Point the domain.** In Vercel or Netlify, add the custom domain and copy the DNS records it gives you into your registrar.
4. **Sign-ups** use Netlify Forms automatically on Netlify: submissions appear under the site's Forms tab, where you can turn on email notifications. To use Mailchimp or Klaviyo instead, paste a form URL into `formEndpoint` near the bottom of `index.html`.
5. **Analytics.** Paste your GA4 or Plausible snippet into the `<head>`.

## Keeping the data fresh

Run `python3 build.py` and `python3 build_calendar.py` after editing `raw_deals.json`, then copy the `rows` into `data/`. Once the GitHub repo exists, the scheduled refresh can commit new data straight to it.

## Before launch

- Have the "How we check" wording and verdict labels read over for legal risk, since the site names retailers.
- Once the site is live, apply to the affiliate networks (Commission Factory, Amazon Associates AU and others). They review your live site before approving you.
